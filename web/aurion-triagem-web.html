Triagem de logs web

Compare logs de acesso com um período de referência para revisar rotas pouco acessadas, rotas novas e mudanças no volume de erros.

Selecionar logs

Use logs de acesso no formato Common ou Combined do Apache ou Nginx, até 10 MiB por arquivo. Escolha períodos comparáveis para o mesmo serviço.

Rotas para revisão

Os sinais ajudam a priorizar a revisão manual e, isoladamente, não confirmam presença de web shell. A análise descarta parâmetros de URL e não exporta IPs de origem.
