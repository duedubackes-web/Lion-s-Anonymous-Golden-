Revisão do histórico Git

Carregue os metadados de commits de um repositório. Busque por assunto, data ou hash e exporte os resultados filtrados.

Como obter o histórico

No GitHub Codespaces, abra o terminal na pasta do projeto e copie o comando abaixo. Cole a saída em Histórico Git.

git log -1000 --format='%H%x09%aI%x09%s'
